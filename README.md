## 🔥 Project Overview

**This tool** is a comprehensive trainer for **A College of Thirst & Claws**. This trainer provides quality-of-life controls for the game's choice-driven Ren'Py experience. It helps players manage story progression, relationship flags, replay access, and achievement-related states without changing the game's core narrative presentation.

**Target Audience:** Players who want to replay story branches, test relationship routes, revisit gallery content, manage progression flags, or recover from missed choices more conveniently.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

The game uses visual-novel navigation rather than free-roaming movement. Progress through dialogue, menus, and choice prompts with the keyboard or mouse. The trainer does not add movement controls.

### Tools & Inventory

A conventional inventory is not part of the game's core structure. Trainer options in this area apply to supported save and progression data rather than physical items.

### World & Environment

Explore the supernatural college and Lanstone through illustrated story scenes, dialogue, and branching decisions. Use progression and choice controls only after saving if you want to compare different outcomes.

### Combat & Weapons

The game does not use a conventional combat system. The trainer provides no combat enhancements; its functions focus on narrative progression, relationships, replay content, and save management.
